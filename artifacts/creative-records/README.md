# Creative record packages

Each child directory is one delivered composition record. A package contains the canonical
manifest snapshot, append-only creative journal, human-readable report, and a digest-bound
index linking the final song WAV and VSQX.

These records preserve the agent's concise creative decisions and evidence across:

`intent → theory → note allocation → IA delivery → arrangement`

They do not contain raw hidden chain-of-thought. Old decisions remain visible and are marked
stale or superseded when their bound manifest objects, hashes, or artifacts change.

Current cold-start records include:

- `tooi-hi-aoi-yoru-ia-20260719-a/`: distant summer-night IA_ROCKS transfer test.
- `kaze-wa-na-o-yobanai-ia-20260719/`: original-IA swordsmen-on-the-cliff
  transfer test, with phrase-grammar/corpus isolation and 23 hash-chained
  decisions.
